# 配音视频对齐

“配音”页支持把字幕配音、原视频和画面处理放进同一条流水线。没有开启对应开关时，原有配音行为保持不变。

## 输入与输出

- 在“字幕模式”中选择字幕文件；需要处理视频时，同时选择“视频文件（可选）”。
- 选择“输出目录”后，生成的配音音频、视频和说话人 sidecar 都会写入该目录；留空时沿用默认输出位置。
- 运行前请确保可以调用 FFmpeg。安装包会优先使用随包的 FFmpeg，开发环境可使用 PATH 中的 `ffmpeg`。

## 对齐控制

- **视频变速**：按每条配音的实际时长调整对应视频片段，尽量保持音画同步。
- **语音间隔**：在字幕时间轴上增加间隔，并同步导出调整后的字幕文件。
- **嵌入硬字幕**：在视频输出阶段烧录字幕；开启已有的字幕样式设置时，会沿用 ASS 或圆角背景样式。

这些选项依赖视频输入。只生成音频时，相关控件会自动禁用。

## 背景音

- **分离人声背景声**：从视频原音中提取人声和背景声。首次使用会按需下载 sherpa-onnx 的 UVR 模型。
- **重新嵌入背景声**：把背景声混入配音，可设置循环和音量。
- **额外背景音频**：选择额外 BGM 后，即使没有启用视频人声分离，也可以直接混音。

分离和说话人识别共用 sherpa-onnx 运行时，模型保存在用户数据目录的模型缓存中，不会写入字幕文件目录。

## 说话人

- **说话人识别**使用 sherpa-onnx 的 ONNX 模型，支持中文和英文；语言设为自动时会根据字幕文本选择模型。
- **仅保留解说员**会按字幕与说话人区间的重叠比例筛选字幕。
- **LLM 复核被删字幕**需要配置现有的 LLM 通道；复核失败时不会阻塞配音，误删候选会保存在 `*.narrator_dropped.srt`。
- 识别结果会写入 `*.speaker.json`，方便检查和后续处理。

说话人识别、解说员过滤和 LLM 复核都依赖视频输入；未选择视频时会跳过识别并保留原字幕。

## 画面效果

- **统一画布**把视频缩放并填充到固定的横屏或竖屏尺寸。
- **随机镜像画面**按 FFmpeg 场景切点决定镜像区间。
- **随机调色**对亮度、对比度和饱和度做轻微随机调整。

画面效果在音频复用后执行，硬字幕在画面效果之后烧录，避免字幕再次被滤镜处理。

## 当前范围

本轮新增设置通过 GUI 配音页使用。CLI 的对应参数、更多分离模型和可选 cv2 场景检测仍属于后置扩展，不影响 GUI 流程。
